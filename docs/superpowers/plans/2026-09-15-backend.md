# Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Nest 12 TypeScript backend (`api`, `quota-service`, `speech-service`, `workflows-service`, `notifications-service`) that authenticates official clients, terminates `/v1/dictate`, transcribes via Groq, enforces word quota, and stores encrypted searchable history.

**Architecture:** New ESM monorepo at `backend/`. Copy *mechanics* from `nestjs-microservices/` (apps + libs, hybrid HTTP/microservice processes, NATS RPC, RabbitMQ + outbox/inbox, TypeORM, Terminus, tracing) and replace the buildings/alarms domain. `api` is the only public process (HTTP `:3000` + WebSocket `/v1/dictate`). Live Opus stays in `api` memory. On `stop`, `api` NATS-`send`s one assembled Ogg to `speech-service`. Quota check/commit is only `quota-service`. After `final`, an outbox row RMQ-`emit`s `workflows.create` (persist transcript) and notification events. Clients couple only through `/v1` HTTP and the dictation protocol.

**Tech Stack:** NestJS 12, TypeScript ESM, Node 24 LTS (`node:24-alpine`), Vitest, Rspack monorepo builder, `@nats-io/transport-node`, RabbitMQ, Redis, Postgres 18, TypeORM, `@nestjs/terminus`, `@nestjs/observe`, `ws` / `@nestjs/platform-ws`, Argon2id, `@nestjs/jwt`, `groq-sdk`. Package manager: **npm**.

**Spec:** `docs/superpowers/specs/2026-09-13-backend-design.md`, `docs/superpowers/specs/2026-09-13-dictation-protocol.md`, `docs/superpowers/specs/2026-09-13-type-by-voice-overview.md`.

**Depends on:** `docs/superpowers/plans/2026-09-15-dictation-protocol.md` must be implemented first. Import `@type-by-voice/dictation-v1` — do not duplicate `QuotaSnapshot`, error codes, `countWords`, or `DictationSession`.

**Follow-on:** `docs/superpowers/plans/2026-09-15-macos-client.md`.

## Global Constraints

- Nest **12**, TypeScript only, never `--language js`. Application source is `.ts`.
- Node **24 LTS**. Dockerfiles `FROM node:24-alpine`. `engines.node` is `>=24.9.0`.
- ESM: `"type": "module"`, NodeNext, relative imports carry `.js` extensions. Vitest, not Jest. Rspack, not webpack. oxlint is acceptable as the Nest 12 default.
- npm. Do not copy `nestjs-microservices/` `package.json` versions, Yarn `only-allow`, or `node:20-alpine`.
- NATS client is `@nats-io/transport-node`, not `nats`. `Transport.NATS` and queue names stay. Packets are JSON strings; custom deserializers use `msg.json()`.
- Every `connectMicroservice(...)` passes `{ inheritAppConfig: true }`.
- `synchronize: process.env.NODE_ENV === 'development'` only.
- Official `platform` values: `macos` | `windows` | `ios` | `android`. Unknown → HTTP `400` `{ "code": "invalid_request" }` or protocol `invalid_request`.
- Live Opus frames stay in `api` and are discarded after `final` or `cancel`. They are never published to NATS or RabbitMQ except the single `speech.transcribe` request (base64 in the JSON packet).
- Quota check/commit is only `quota-service`. Finish-then-block: never truncate an in-flight utterance.
- Word count: `countWords` from `@type-by-voice/dictation-v1` (trim, split on whitespace runs). Server is the sole counter.
- Transcript ciphertext in the database. Never log `text`.
- Default free plan: 2000 words, 7-day period, `audio_minutes_ceiling` **180**.
- Access JWT TTL **15 minutes**. Refresh TTL **30 days**, stored hashed, rotated, unique active `(user_id, device_id)`.
- Password hashing: Argon2id.
- Max concurrent dictation sessions per user: **2**. Max audio duration: **120 s**.
- Prefer `@nestjs/observe` for process tracing. Keep `libs/tracing` for `x-trace-id` + `TracingClientProxy` request correlation (`requestId`, `platform`, `deviceId`).
- Use `const`/`let`, never `var`. Comments only where the code cannot explain itself.
- Do not modify `nestjs-microservices/` except to read it. Do not ship `alarms-generator`.

- [ ] **Step 3: Implement**

Persist `device_id` as a lowercase UUID string so protocol identity matching is case-stable. Capture `user_agent` from the HTTP header as a raw fallback; never parse it for `platform`. Reuse session rows. Refresh: lookup hash, ensure not revoked/expired, compare `platform`/`deviceId`, revoke old, insert new, return new pair. Logout sets `revoked_at`.
